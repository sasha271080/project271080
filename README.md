# Контроллер коллекторного двигателя (Blue Pill STM32F103C8T6)

## Аппаратная часть

| Компонент | Пин Blue Pill | Примечание |
|---|---|---|
| ACPL-C790 Vout+ | PA0 (ADC1_IN0) | Дифф. выход датчика тока (изолированный) |
| ACPL-C790 Vout- | PA1 (ADC1_IN1) | Дифф. выход датчика тока |
| Потенциометр (обороты) | PA2 (ADC1_IN2) | 0..3.3В |
| Потенциометр (уставка тока / момент) | PA3 (ADC1_IN3) | 0..3.3В. Ограничитель момента при TL1 |
| ШИМ (транзистор) | PA6 (TIM3_CH1) | 30 кГц |
| Энкодер (импульс) | PB5 (EXTI5) | Open collector, подтяжка 510 Ом к 3.3В |
| Кнопка ВКЛ/ВЫКЛ инвертора | PB12 | Активный LOW: замкнута на землю = ВКЛ |
| USB | PA11 (DM), PA12 (DP) | CDC Virtual COM Port 115200 |
| Светодиод (индикация) | PC13 (LED) | Активный LOW |

**Параметры датчика (текущие):**
- Шунт: **0.075 Ом** (три в параллель: 0.3 + 0.2 + 0.2)
- Усиление ACPL-C790: 8.2
- **1.00 А** = 763 отсчёта АЦП (75 мВ × 8.2 → 615 мВ)
- Полная шкала (4095) ≈ 5.37 А (линейность датчика ≈ до 2.7 А, но для защиты сработает)

## Архитектура токовых защит

Система имеет три уровня защиты, независимые друг от друга:

| Уровень | Команда | От чего зависит | Реакция |
|---|---|---|---|
| **Торк-лимит (ограничитель момента)** | `TL1` (вкл) / `TL0` (выкл) | Потенциометр PA3 (60..100% от CURRENT_LIMIT) | Плавно ограничивает пиковый duty. Не аварийный — мягкое ограничение момента |
| **Тепловая (I²t)** | `TE1` (вкл) / `TE0` (выкл) | **Фиксированный** CURRENT_LIMIT, не зависит от PA3 | Аварийный стоп при превышении (смоделировано тепловое реле) |
| **Максимальная (×2)** | `ME1` (вкл) / `ME0` (выкл) | **Фиксированный** CURRENT_LIMIT × 2, не зависит от PA3 | Мгновенный стоп при токе > 2× номинала |

При `TL0` (торк-лимит выключен) двигатель работает на полном `CURRENT_LIMIT`
без ограничения момента — защиты (тепловая и максималка) остаются активными.

## Режимы токовой защиты (0/1/2/3)

| Команда | Режим | Поведение |
|---|---|---|
| `0` | **Мягкое выключение** | ПИД держит обороты. Ток ≥ уставки несколько кадров → ШИМ гаснет → пауза → автовключение |
| `1` | Отладка | Игнорирует кратковременные скачки; срабатывает при превышении > 2 сек |
| `2` | Тест | Защита полностью отключена |
| `3` | **Тяговый (min-селектор)** | Двойной контур: ПИД + токовый потолок. Держит ток на уставке |

## Форматы вывода по USB

### JSON
```
{"cur":...,"rms":...,"pot":...,"rpm":...,"rpm_set":...,"limit":...,"auto":...,"rip":...,"on":...,"on_sw":...,"cl":...,"tl":...,"ss":...,"ru":...,"rd":...,"te":...,"me":...,"vs":...,"vr":...,"prot":...,"json":...,"mv":...,"uv":...}
```

| Поле | Описание |
|---|---|
| `cur` | Ток (дифф.) в отсчётах АЦП |
| `rms` | RMS тока |
| `pot` | Сырое значение PA2 (обороты) |
| `rpm` / `rpm_set` | Измеренные / заданные обороты |
| `limit` | 1 если сработала какая-либо защита |
| `auto` / `rip` | Адаптивный ПИД / пульсации |
| `on` / `on_sw` | Состояние инвертора / режим управления |
| `cl` | Текущий порог тока (отсчёты) |
| `tl` | 1 = торк-лимит (PA3), 0 = жёсткий CURRENT_LIMIT |
| `ss` / `ru` / `rd` | Цифровой конденсатор / разгон / торможение |
| `te` / `me` | Тепловая / максимальная защита |
| `vs` / `vr` | Виртуальный задатчик оборотов |
| `prot` / `json` | Режим защиты / формат вывода |
| `mv` | Напряжение на двигателе (расчётное, В) |
| `uv` | Сетевое напряжение AC (заданное, В) |

| `TE0` / `TE1` | Тепловая защита ВЫКЛ / ВКЛ |

## Сохранение в Flash (команда `w`)

Записывается: Kp/Ki/Kd, режим защиты, статус авто/пульсаций/TL/TE/ME,
SS/RU/RD, пауза, порог тока. При старте `Cfg_Load()` восстанавливает.
Уставка тока — всегда с PA3 (TL1) или CURRENT_LIMIT (TL0).

## Тепловая защита (TE0/TE1)

Имитирует тепловое реле. Накопление **превышения** над `CURRENT_LIMIT`
(не над PA3!):

```
each_frame:
  if ток > CURRENT_LIMIT:  integral += (превышение)² / 64
  else:                    integral -= integral / 256
  if integral > 10M:       аварийный стоп
```

При `TL0` и токе ровно `CURRENT_LIMIT` — превышения нет, тепловушка не сработает.

## Максимальная защита (ME0/ME1)

Порог: `MAX_PEAK_LIMIT = CURRENT_LIMIT × 2`. Сейчас: 763 × 2 = 1526 ≈ 2.0 А.
Мгновенный стоп. Не зависит от PA3.

## Напряжение на двигателе (UVxxx / mv)

Расчётное значение: `motor_v = duty_now × line_voltage × √2 / ARR` (действующее, В).
- Сеть по умолчанию `230` В — меняется командой `UVxxx`
- С уменьшением оборотов (меньше duty) — напряжение падает
- Показывается в тунере (вторая строка состояния) и в JSON (`mv`)

## PID Tuner (pid_tuner.py)

В строке состояния отображается:
- `[Тепл.:ВКЛ/ВЫКЛ]` — статус тепловой защиты
- `[Макс.:ВКЛ/ВЫКЛ]` — статус максимальной защиты
- `[Момент:PA3]` при TL1, `[Момент:макс]` при TL0
- Обороты сглаженные (экспоненциальный фильтр, не дёргаются)
- Все ползунки: Kp/Ki/Kd, SS/RU/RD, виртуальные обороты
- **Вторая (синяя) строка:** напряжение на двигателе, сеть, заполнение ШИМ

## Как сменить шунт / пересчитать ток

1. Установил новый шунт сопротивлением R (Ом)
2. Формула: `ADC_отсчёта = 4095 × (R × I × 8.2) / 3.3`
   - Где I — желаемый номинальный ток в амперах
   - 8.2 — усиление ACPL-C790
   - 3.3 — опорное напряжение АЦП
3. Пример: шунт 0.075 Ом, номинал 1 А:
   `4095 × (0.075 × 1 × 8.2) / 3.3 = 4095 × 0.615 / 3.3 ≈ 763`
4. В `main.c` меняется `#define CURRENT_LIMIT` на это число
5. В `pid_tuner.py` меняется `ADC_TO_A = 1.0 / <новое_число>`
6. MAX_PEAK_LIMIT подтянется автоматически (×2)
7. CL_MIN_PCT — минимум в процентах от CURRENT_LIMIT

## Диапазон оборотов

- `RPM_MAX = 6000` (в main.c) — потенциометр и виртуальный задатчик
- Зоны автоПИД (6 зон):

| Зона | Kp | Ki | Kd |
|---|---|---|---|
| 0..150 | 120 | 60 | 250 |
| 150..500 | 180 | 90 | 280 |
| 500..1000 | 240 | 110 | 260 |
| 1000..2000 | 300 | 130 | 200 |
| 2000..4000 | 350 | 140 | 180 |
| 4000..6000 | 380 | 150 | 160 |

Энкодер (60 имп/об, период-метод) свободно работает до 6000 об/мин (период 167 мкс).
