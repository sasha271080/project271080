# Контроллер коллекторного двигателя

## Аппаратная часть

| Компонент | Пин Blue Pill | Примечание |
|---|---|---|
| ACPL-C790 Vout+ | PA0 (ADC1_IN0) | Дифф. выход датчика тока (изолированный) |
| ACPL-C790 Vout- | PA1 (ADC1_IN1) | Дифф. выход датчика тока |
| Потенциометр (обороты) | PA2 (ADC1_IN2) | 0..3.3В |
| Потенциометр (уставка тока / момент) | PA3 (ADC1_IN3) | 0..3.3В. Ограничитель момента при TL1 |
| ШИМ (транзистор) | PA6 (TIM3_CH1) | 30 кГц |
| Энкодер (импульс) | PB5 (EXTI5) | Open collector, подтяжка 510 Ом к 3.3В |
| Кнопка ВКЛ/ВЫКЛ инвертора | PB12 | Активный LOW: замкнута на землю = ВКЛ |
| USB | PA11 (DM), PA12 (DP) | CDC Virtual COM Port 115200 |
| Светодиод (индикация) | PC13 (LED) | Активный LOW |

## ESP8266 development area

Для разработки веб-интерфейса и Wi‑Fi-обвязки создан отдельный каталог:

- `esp8266/README.md` — обзор и цель модуля
- `esp8266/esp8266_ap_dashboard.ino` — базовый sketch ESP8266 AP + веб-страница
- `esp8266/COMMANDS.md` — команды STM32 и HTTP-API панели, поля JSON, коды аварий
- `esp8266/PROJECT_MEMORY.md` — связь STM32 ↔ ESP8266, принятые решения и грабли

Идея следующая:
- STM32 остаётся основой управления двигателем;
- ESP8266 работает как Wi‑Fi мост / точка доступа для смартфона;
- смартфон получает JSON/веб-страницу и отправляет команды в моторный контроллер;
- протокол команд совпадает с уже существующими командами STM32 (`ON`, `OF`, `j`, `KP...`, `KI...`, `KD...`, `TL...`, `TE...`, `ME...`).

Эта структура нужна для дальнейшего расширения интерфейса, панели управления и мобильного мониторинга без ломки основного управляющего кода STM32.
