# Команды STM32 и HTTP-API панели

Источник истины — `Core/Src/mc_cmd.c` (разбор) и `Core/Inc/mc.h` (границы).
Ниже — то же самое, но с диапазонами, которые прошивка реально принимает.

## Формат линии

- ASCII, команда заканчивается `\n` или `\r`; прошивка сама срезает переводы строки.
- **Эха нет.** Отправили `ON` — ответа не будет, смотрите телеметрию (`on`, `on_sw`).
- Приёмник в `mc_wifi.c` копит до 64 байт: команда длиннее — сбрасывается как мусор.
- Число — только цифры, без знака и пробелов; больше 1 000 000 — отбрасывается.
- Если число вне диапазона, команда **молча игнорируется** (без ошибки).

## Управление инвертором

| Команда | Действие |
|---|---|
| `ON` | программный пуск (`inverter_sw = 1`) |
| `OF` | программный стоп (`inverter_sw = 2`) |
| `HB` | вернуть управление аппаратной кнопке PB12 (`inverter_sw = 0`) |
| `RS` | снять защёлку аварии (`trip = 0`, поднять MOE) |
| `PG` | пинг: обновляет `last_cmd_ms`, больше ничего не делает |

## Задатчик оборотов

| Команда | Диапазон | Действие |
|---|---|---|
| `RVxxx` | `rlo..rhi` (по умолчанию 30..6000) | виртуальное задание оборотов, включает `rv` |
| `RP` | — | вернуть обороты на потенциометр PA2 |
| `RLxxx` | ≥ 30 и ≤ `rhi − 100` | нижняя граница рабочего диапазона |
| `RHxxx` | ≤ 6000 и ≥ `rlo + 100` | верхняя граница |

## Режимы

| Команда | Действие |
|---|---|
| `0` | защита: мягкое выключение (рабочий) |
| `1` | защита: отладка (только длительная перегрузка) |
| `2` | защита **отключена** (тест) |
| `3` | тяговый режим, min-селектор |
| `a` / `m` | адаптивный ПИД ВКЛ / ВЫКЛ (ручные коэффициенты) |
| `r` / `s` | автоконтроль пульсаций ВКЛ / ВЫКЛ |
| `OL1` / `OL0` | разомкнутый контур (ШИМ без ОС) |
| `OPxxx` | 0..900 (промилле ШИМ, 900 = 90 %) — только при `OL1` |
| `OT1` / `OT0` | задание ШИМ с потенциометра / от терминала |
| `TQ1` / `TQ0` | тяговый режим по моменту (взаимоисключающ с `OL`) |

## Защиты

| Команда | Действие |
|---|---|
| `TE1` / `TE0` | тепловая (I²t) ВКЛ / ВЫКЛ |
| `ME1` / `ME0` | максимальная (×2 от `CURRENT_LIMIT`) ВКЛ / ВЫКЛ |
| `TL1` / `TL0` | торк-лимит по PA3 ВКЛ / ВЫКЛ |
| `CLxxx` | предел тока в отсчётах АЦП, 50..3000 (763 = 1 А) |
| `CNxxx` | «пол» тока, отсчёты, 5..`CL` |
| `Pxxxx` | пауза после срабатывания, 100..30 000 мс |

## Контуры

| Команда | Диапазон | Действие |
|---|---|---|
| `KPxxx` / `KIxxx` / `KDxxx` | 0..5000 | коэффициенты скорости **и** переключение в ручной режим (`m`) |
| `CPxxx` | 1..5000 | Kp контура тока |
| `CIxxx` | 0..5000 | Ki контура тока |
| `SSxxx` | 1..100 | «цифровой конденсатор»: скорость нарастания ШИМ |
| `RUxxx` / `RDxxx` | 1..100 | разгон / торможение уставки, об/мин за кадр |
| `FRn` | 1..4 | сдвиг фильтра оборотов |
| `FDn` | 1..4 | сдвиг фильтра D-звена |
| `SLn` | 1..8 | делитель контура скорости |
| `UVxxx` | 100..300 | напряжение сети для расчёта `mv` |
| `BTxxx` | 0 или 100..5000 | форсаж при набросе нагрузки, мс |

## Тяговый режим (момент)

| Команда | Диапазон | Действие |
|---|---|---|
| `TCxxx` | 30..6000 | потолок оборотов |
| `TBxxx` | 0..2000 | полоса плавного сброса тока |
| `TZxxx` | 0..500 | мёртвая зона ручки PA3 |
| `TRxxx` | 1..200 | темп набора тока |
| `TMxxx` | 0..3000 | свой предел тока |
| `TFxxx` | 0..1000 | ток трогания |
| `TSxxx` | 0..600000 | таймаут стоянки под током, мс (0 = выкл) |

## Таблица зон автоПИД

| Команда | Действие |
|---|---|
| `ZD` | выдать таблицу зон (`{"zones":[[rpm,kp,ki,kd],…]}`) |
| `ZR` | вернуть заводские зоны |
| `Z<n>Pxxx` | Kp зоны `n` (0..5), 0..5000 |
| `Z<n>Ixxx` | Ki зоны `n`, 0..5000 |
| `Z<n>Dxxx` | Kd зоны `n`, 0..5000 |
| `Z<n>Rxxx` | обороты узла `n`, 50..12000 |

## Служебные

| Команда | Действие |
|---|---|
| `j` / `o` | формат вывода: JSON / O-кадры (бинарный поток для осциллографа) |
| `w` | сохранить настройки во Flash |
| `CF` | сброс настроек к заводским (стирание конфига) |
| `WE1` / `WE0` | мост Wi-Fi ВКЛ / ВЫКЛ |

`w` и `CF` выполняются в главном цикле, а не в прерывании: стирание страницы
Flash занимает 20–40 мс, и это время ШИМ держит последнее заполнение.
**При `on=1` обе команды молча игнорируются** (`mc.c:553`, `mc.c:676`) —
сначала остановите двигатель. Ответа на `w` нет — проверяйте, что настройки
пережили перезагрузку.

## HTTP-API панели

| Адрес | Ответ |
|---|---|
| `GET /` | HTML-панель (≈20 КБ, из flash) |
| `GET /api/data` | последний целый JSON-кадр STM32, `application/json` |
| `GET /api/cmd?c=<команда>` | `ok` или `400 bad cmd` |
| `GET /api/info` | JSON состояния моста |

`/api/data` отдаёт два заголовка состояния:

| Заголовок | Значение | Смысл |
|---|---|---|
| `X-Stm` | `ok` | кадр свежее 1.5 с |
| | `stale` | кадр есть, но старше — значения последние известные, не живые |
| | `none` | кадров ещё не было, тело `{}` |
| `X-Frame-Age` | мс | возраст последнего кадра |

Панель по `stale`/`none` гасит цифры и останавливает график: замороженные
показания не выглядят как живые.

`/api/cmd` проверяет команду по белому списку: 1–40 символов, только печатный
ASCII, известный префикс и цифры после него. Это защита от опечатки в URL, а не
от злоумышленника — сеть локальная.

```bash
# пуск и стоп
curl "http://192.168.4.1/api/cmd?c=ON"
curl "http://192.168.4.1/api/cmd?c=OF"

# задать 1500 об/мин и вернуть потенциометр
curl "http://192.168.4.1/api/cmd?c=RV1500"
curl "http://192.168.4.1/api/cmd?c=RP"

# снять аварию
curl "http://192.168.4.1/api/cmd?c=RS"

# телеметрия
curl -s "http://192.168.4.1/api/data"

# состояние моста
curl -s "http://192.168.4.1/api/info"
```

Из JavaScript (например, со своей страницы в той же сети):

```js
await fetch('http://192.168.4.1/api/cmd?c=RV1200');
const t = await (await fetch('http://192.168.4.1/api/data')).json();
console.log(t.rpm, t.cur / 763);
```

`/api/data` и `/api/info` отдают `Access-Control-Allow-Origin: *`, так что
обращаться можно и с другой страницы.

## Поля JSON-кадра

Кадр формируется в `mc.c` (функция `telemetry()`): **64 поля**, ~700 байт,
10 раз в секунду.

| Поле | Единица | Смысл |
|---|---|---|
| `cur` | отсчёты АЦП | ток (763 ≈ 1 А) |
| `rms` | отсчёты | RMS тока |
| `pot` | отсчёты | потенциометр оборотов PA2 |
| `rpm`, `rpm_set` | об/мин | измерено / задание после рампы |
| `limit` | 0/1 | сработала любая защита |
| `auto`, `rip` | 0/1 | адаптивный ПИД / контроль пульсаций |
| `on`, `on_sw` | 0/1, 0..2 | инвертор включён / источник (0 кнопка, 1 `ON`, 2 `OF`) |
| `cl`, `cls`, `cn` | отсчёты | действующий порог / заданный / «пол» |
| `tl`, `te`, `me` | 0/1 | торк-лимит / тепловая / максимальная |
| `ss`, `ru`, `rd` | — | плавность |
| `vs`, `vr` | 0/1, об/мин | виртуальный задатчик / его значение |
| `rlo`, `rhi` | об/мин | рабочий диапазон |
| `prot`, `json` | 0..3, 0/1 | режим защиты / формат вывода |
| `ol`, `olduty` | 0/1, промилле | разомкнутый контур / его задание ШИМ |
| `mv`, `uv` | В | напряжение двигателя (расчёт) / сети |
| `duty` | промилле | заполнение ШИМ (900 = 90 %) |
| `iref` | отсчёты | уставка тока от контура скорости |
| `trip` | 0..11 | код аварии, см. ниже |
| `kp`,`ki`,`kd` | — | действующие коэффициенты |
| `kpu`,`kiu`,`kdu` | — | заданные вручную |
| `kpm`,`kdm` | — | множители автокоррекции пульсаций |
| `cikp`,`ciki` | — | контур тока |
| `ovr` | — | переполнения АЦП |
| `esp` | % | разброс периода энкодера |
| `eduty`,`eg`,`eok` | — | диагностика энкодера: скважность, дребезг, валидные импульсы |
| `bst`,`bt` | 0/1, мс | идёт форсаж / его длительность |
| `tq`, `tcap`, `tband`, `tdz` | 0/1, об/мин, об/мин, отсчёты | тяговый режим: включён, потолок, полоса, мёртвая зона |
| `trate`, `timax`, `tfloor`, `thold` | отсчёты, отсчёты, отсчёты, мс | темп набора, предел, ток трогания, таймаут стоянки |
| `wtx`,`wdr`,`wrx`,`won` | — | диагностика Wi-Fi моста на стороне STM32 |

## Коды аварий (`trip`)

| Код | Причина | Снимается |
|---|---|---|
| 0 | нет аварии | — |
| 1 | длительная перегрузка (OC) | автовозврат в режиме 0 / `RS` / кнопка PB12 |
| 2 | мгновенный пик тока (`ME1`) | `RS` |
| 3 | тепловая I²t (`TE1`) | `RS` |
| 4 | нет отклика энкодера | `RS` / кнопка PB12 |
| 5 | разгон выше `RPM_MAX` +20 % | `RS` |
| 6 | стоянка под током в тяге (`TS`) | `RS` / кнопка PB12 |
| 7 | датчик тока недостоверен | `RS` |
| 8 | обрыв якоря / щёток | `RS` |
| 9 | потеря связи с ПК (`TRIP_COMM`) | `RS` |
| 10 | был сброс по watchdog | `RS` |
| 11 | аппаратный срыв `TIM1_BKIN` | `RS` / кнопка PB12 |
